# Video Game Sales – Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a real-world Video Game Sales dataset using Python, Pandas, Matplotlib, and Seaborn.

The objective is to understand video game sales trends, explore relationships between different variables, identify missing values, and discover meaningful insights from the dataset.

## Dataset
- Dataset: Video Game Sales
- Source: Kaggle
- Original Records: 16,598 rows
- Columns: 11
- File: `vgsales.csv`

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Project Workflow
1. Data loading and inspection
2. Dataset structure and data type analysis
3. Missing value identification and visualization
4. Data cleaning and preprocessing
5. Descriptive statistical analysis
6. Categorical value counts
7. Data visualization and trend analysis
8. Interpretation of findings

## Key Findings
- The Action genre recorded the highest global sales, followed by Sports and Shooter.
- PlayStation 2 (PS2) had the highest global sales among gaming platforms.
- Video game releases and sales peaked around 2008.
- The mean global sales were approximately 0.54 million, while the median was 0.17 million, indicating a right-skewed distribution.
- Approximately 87.4% of games recorded global sales below 1 million.

## Missing Value Analysis
- Year: 271 missing values
- Publisher: 58 missing values

Missing values were handled during data cleaning by removing records with missing Year values and replacing missing Publisher values with "Unknown".
